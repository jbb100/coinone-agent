- 날짜: 2026-08-01
- 상태: **폐기 (백테스트 불합격)** — 사용자 결정
- 배경: 장기 전략(KAIROS-Simple)이 횡보하는 동안 KRW 예비금 일부(상한 15%)로 짧은 알파 수익을 노리는 전략 추가 검토. 구현 전 백테스트 우선 검증 방침에 따라 신호 로직만 백테스트로 선검증했고, 불합격하여 구현하지 않기로 결정.

## 1. 검증한 설계안

- **전략**: 4시간봉 평균 회귀 스윙 (롱 온리 — 코인원 현물 전용)
- **레짐 필터**: BTC 일봉 ADX(14) < 25 AND |종가/50일SMA − 1| ≤ 10% → 횡보 판정 시에만 신규 진입
- **진입**: RSI(14, Wilder) < 30 AND 종가 ≤ 볼린저(20, 2σ) 하단 AND (중심−하단)/하단 ≥ 1.5%
- **청산**: 종가 ≥ BB 중심선(익절) | 진입가 −3%(손절) | 7일(타임스톱)
- **사이징**: 버킷 리스크 1.5%/거래 ÷ 손절 3% = 버킷의 50%, 동시 2포지션
- **합격 기준(사전 정의)**: 횡보 구간 승률 ≥ 55%, 하락장에서 레짐 필터의 진입 차단 확인

## 2. 백테스트 방법

- 기간/데이터: 2021-01 ~ 2026-08, Binance 4h봉 (BTC/ETH/XRP/SOL USDT), 레짐은 일봉
- 비용: 1차 검증은 수수료 0.2% + 슬리피지 0.2% (편도 0.4%). 코인원 실제 수수료(2026-08 확인, KRW 마켓, Maker=Taker)는 일반 0.25% / 바우처 0.04% / Open API 0.02%이나, **낮은 티어는 프로모션 성격이라 지속을 전제할 수 없어 일반 0.25%를 보수 기준으로 채택** (사용자 결정). §3.1에서 수수료 가정별 재검증
- 체결: 신호봉 **마감 후 다음 봉 시가** 체결 (look-ahead bias 차단), 손절은 봉 저가 관통 시 보수적 체결(갭 하락 시 시가)
- 사이징: 버킷 자본 비례 동적 (복리 반영)
- 파라미터: 전부 관례값(RSI 14/30, BB 20/2, ADX 25) — 이 데이터에 튜닝하지 않음

## 4. 실패 원인 분석

1. **신호 자체에 엣지 없음 (결정적)**: 비용 0원에서도 거래당 평균 −0.47%. 2021~26 크립토 4h봉에서 "RSI<30 + BB 하단 접촉"은 반등보다 하락 지속과 더 자주 동행. 교차 검증 결과 비용 문제가 아니라 신호 문제.
2. **손절 × 평균 회귀의 구조적 상충**: 손절 3%는 4h 노이즈 폭 이내 → 회귀 완성 전 손절(승률 34%). ATR로 넓히면 승률 45%까지 회복되나 손실 폭 확대로 PF 불변. 문헌상 MR 승률 55-65%는 대체로 손절 없는 조건의 수치이며, 무손절은 리스크 원칙(자동 손절 필수) 위반이라 채택 불가.
3. **레짐 필터의 원리적 한계**: 급락은 저변동 횡보 판정 중에 발생. 2022-11 FTX 붕괴 직전이 초저변동 횡보 구간이라 필터가 열려 있었고 해당 월에만 버킷 −25%. 방향성 조건(BTC>200일MA)을 추가해도 2023~25 손실 지속.
4. **비용 구조 (부차 요인)**: 평균 보유 ~1일, 기대 익절폭 ~2%에서 보수 기준 왕복 0.9%는 기대수익의 45%. 단 §3.1이 보이듯 비용을 완전히 제거해도 손실이므로, 비용은 손실을 키우는 부차 요인이지 근본 원인이 아님.

## 5. 결론과 교훈

- **4h 이하 단기 평균 회귀는 수수료와 무관하게 성립하지 않는다** (무비용에서도 PF < 1). 그리드 트레이딩 등 유사 단기 유형도 같은 가격 구조(과매도의 하락 지속)를 이용하므로 전망이 밝지 않음.
- **수수료 정책**: 백테스트는 코인원 일반 수수료 0.25%를 보수 기준으로 사용한다. Open API 0.02%·바우처 0.04% 티어는 프로모션 성격으로 간주하고 성과 주장의 전제로 삼지 않는다. 이 기준은 기존 장기 전략 백테스트(0.2% 가정)에도 소급해 큰 영향 없음(연 거래 ~40회 미만, 회전율 낮음).
- 장기 전략(주간 DCA 역발상 승수 + 밴드 리밸런싱)이 이미 같은 방향의 엣지("공포에 매수")를 더 낮은 회전율·비용으로 수확 중. 단기 시간축에서 같은 엣지를 추가 추출할 여지는 확인되지 않았다.
- 향후 단기 전략을 재검토할 경우, 이 문서의 결과를 기준선으로 삼고 **신호의 비용 제로 엣지부터** 확인할 것.
